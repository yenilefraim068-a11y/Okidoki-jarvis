JARVIS Yönetim

Yeni APK'yı buradan yükle. GitHub'a girmene gerek yok. Yükleyince ana siteki indirme düğmesi ve uygulamadaki güncelleme otomatik yeni sürümü görür.

İlk kez mi? Erişim anahtarı nasıl alınır
  1. github.com'a giriş yap. Sağ üstte profil resmin → Settings.
  2. En altta Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Ad: jarvis-yukle. Süre: 1 yıl.
  4. Repository access: Only select repositories, okidoki-jarvis seç.
  5. Permissions → Repository permissions → Contents: Read and write.
  6. Generate token de. Çıkan github_pat_... yazısını kopyala, aşağıya yapıştır. Bir daha gösterilmez.
