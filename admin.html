JARVIS Yönetim

APK'yı seç, sürüm numarasını yaz, yayınla. Büyük dosyalar (300 MB+) da çalışır. Yüklemeden sonra GitHub birleştirip sürümü yayımlar, 1-3 dakika sürer.

İlk kez mi? Erişim anahtarı nasıl alınır
  1. github.com → sağ üstte profil resmin → Settings.
  2. En altta Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Ad: jarvis-yukle. Süre: 1 yıl.
  4. Repository access: Only select repositories → okidoki-jarvis.
  5. Repository permissions altında iki izin ver: Contents: Read and write ve Workflows: Read and write.
  6. Generate token. Çıkan github_pat_... yazısını kopyala, aşağıya yapıştır. Anahtarı kimseyle paylaşma.
